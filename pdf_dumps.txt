Notes:  
\n--- Page 23 ---\n 23 / 37 
 
A. Open time and close time:  
1. The open and close times for timing points are determined 
relative to the event start time. For example, if an event 
begins at 09:00:00: 
• Start Timing Point: 
o Open Time: The open time should be set to 00:00:00 (the 
event start time). And please do not set to 09:00:00, 
which means the event starts at 18:00:00. 
o Close Time: The close time must be set to a time after 
the last participant has passed the start timing point. 
• Finish Timing Point: 
o Open Time: The open time should be set to a time before 
the first participant passes the finish timing point. 
o Close Time: The close time must be set to a time after 
the last participant has passed the finish timing point. 
2. For this situation: same location for different timing points. 
For example, if a start point and a finish point are at the 
same location, the open time of the finish point must be later 
than the close time of the start point. This setup ensures 
that the timing system accurately records participants' start 
and finish time. If the finish point were open while 
participants are still starting, it could cause confusion and 
incorrect timing data. 
B. Sort: first time record and last time record: Normally, we 
take first time record at the start point and the last time 
record at the other timing points such as finish, check 
point. 
Reason for the last time record at the start time: Choosing 
the last time ensures that the actual start time is used, 
particularly in races where participants may warm up or 
prepare near the start line. 
Reason for the first time record at the other timing points: 
The first crossing time typically represents the actual time 
the participant reaches a timing point, capturing the 
earliest valid time. 
C. Fastest speed: The maximum speed setting is a key component 
of the scoring software’s calculation logic. It is used to 
filter out invalid data by excluding any readings that exceed 
the predefined speed threshold. This ensures that only 
realistic data is used in result calculations. The software 
uses this rule to validate that the results are within the \n--- Page 24 ---\n 24 / 37 
 
expected range of performance for the event. To maintain 
accuracy and fairness in scoring, the maximum speed setting 
should be configured based on actual event conditions or 
historical data. And it is also a baseline to set the open 
time for finish and check points.
